# PastureStack Container Cron v0.6.1

This maintenance candidate keeps the preserved upstream history and the
reviewed PastureStack compatibility behavior from v0.6.0.

## Security changes

- Pins Docker API requests to the endpoint parsed at process startup.
- Rejects Docker endpoint credentials, paths, queries, fragments, invalid
  ports, and HTTP redirects.
- Preserves Unix, TCP, HTTP, and HTTPS endpoint compatibility while requiring
  TLS 1.2 or newer for HTTPS.
- Adds regression coverage for endpoint pinning, redirect rejection, unsafe
  endpoint components, and TCP compatibility.
- Resolves Ubuntu packages from a dated snapshot with exact direct-package
  versions.
- Verifies Go and Docker CLI downloads with architecture-specific SHA-256
  values before use.
- Updates the disposable build environment to Docker CLI 29.7.2 and omits the
  latest Docker Buildx binary because its embedded Moby daemon code still has
  applicable High-severity findings.
- Updates `golang.org/x/sys` to v0.44.0, which removes GO-2026-5024 from the
  dependency graph.
- Adds raw source, product, runtime, and builder scans, CycloneDX SBOMs, and an
  exact vulnerability-ID/package-PURL OpenVEX review for the disposable build
  environment.

## Deployment

After the release gate succeeds, use
`ghcr.io/pasturestack/container-cron:v0.6.1`. Do not expose an image digest in
the user interface.

The service has host-equivalent Docker API privileges. Deploy it only as a
trusted global infrastructure service, and use verified TLS for remote Docker
daemons.
