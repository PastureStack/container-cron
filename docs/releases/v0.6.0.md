# PastureStack Container Cron v0.6.0

This is the first reviewed PastureStack runtime release after the preserved
upstream history.

## Runtime changes

- Supports current Docker Engine event and container APIs.
- Uses the neutral `container-cron` command and retains the historical
  executable alias for staged upgrades.
- Builds on the reviewed Ubuntu 26.04 base.
- Uses Go 1.26.5, including the current standard-library security fixes.
- Includes race-tested scheduling, bounded event-stream retry behavior, and an
  isolated start/stop lifecycle smoke test.

## Deployment

Use `ghcr.io/pasturestack/container-cron:v0.6.0`.

The service requires the host Docker socket and therefore has host-equivalent
administrative access. Deploy it only as a trusted global infrastructure
service.
